# Бардачок

Понятный автомобильный справочник: девять тем, 121 заметка, поиск и памятка с сохранением отметок.

**Сайт:** https://lonagi.github.io/bardachok/

## Что внутри

- Девять глав об устройстве, обслуживании и безопасном вождении.
- Поиск по всем заметкам, включая скрытые главы. Открывается кнопкой, `/` или `Ctrl/Cmd + K`.
- Светлая и тёмная темы, выбор темы по настройке устройства.
- Памятка из девяти пунктов. Отметки сохраняются только в браузере.
- Адаптивная версия, навигация с клавиатуры и печать всех глав.
- Полный текст доступен без JavaScript. Нет аналитики, трекеров, аккаунтов и внешних запросов при чтении.

## Локальный запуск

```sh
python3 -m http.server 8785
```

Открыть http://127.0.0.1:8785/.

## Редактирование

- `content.json`: главы, заметки, памятка и пояснения по безопасности.
- `templates/index.html`: каркас страницы.
- `style.css`: оформление и адаптивность.
- `app.js`: поиск, навигация, темы, сохранение отметок.
- `guide.md`: версия конспекта для скачивания.

После изменения содержания или шаблона:

```sh
python3 build.py
node --check app.js
```

Сборка обновляет `index.html` и `content.js`. Зависимостей и менеджера пакетов не требуется. Готовые файлы хранятся в репозитории; GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает Jekyll.

## Материалы

Текст основан на самостоятельном конспекте девяти выпусков Стаса Асафьева об автомобилях. Это независимый проект, без связи с автором исходных видео. Полные расшифровки и сами видео не публикуются. Конкретные процедуры и регламенты необходимо сверять с руководством автомобиля.

Иллюстрации созданы для проекта с помощью генерации изображений. Они используются как редакционные иллюстрации, а не технические схемы. Шрифт **Onest** распространяется по SIL Open Font License 1.1 (`assets/fonts/OFL.txt`). Иконки **Phosphor 2.1.1** распространяются по MIT (`assets/icons/LICENSE`). Все ресурсы размещены локально.

Три пояснения по безопасности сверены с руководствами Volvo (крепление багажа и срабатывание подушек) и Volkswagen (ABS/ESC).
